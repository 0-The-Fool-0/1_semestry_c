# First-Semester C++ Labs

A small archive of introductory C++ laboratory assignments, kept in their original lab folders.

## Contents

- **Labs 1–8** — separate exercises in basic programming, numerical calculations, file input/output, and simple data structures.
- **`lab7/`** — includes a `Point4D` header and related source files.
- **`lab6/` and `lab8/`** — include sample text input/output files used by the exercises.

The original filenames and folder structure are preserved to match the coursework. This repository is an archive of individual assignments, not one combined application.

## Build and run

There is no root-level CMake, Make, or Visual Studio solution in this repository. Inspect the selected lab's source files and compile the required `.cpp` files together with a C++ compiler. Some labs expect their text input files to be available in the process working directory.

A single unified build command is not provided because the exercises have different source-file layouts and dependencies.

## Notes

- Input/output text files are retained where they are part of an exercise.
- The repository has not been converted into a single application.
- Review each lab independently before relying on its output.
