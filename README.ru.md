# Лабораторные работы первого семестра — C++

[English version](README.md)

Архив вводных лабораторных работ по C++, сохранённых в отдельных каталогах. Названия исходных файлов и структура папок оставлены максимально близко к оригинальным материалам.

## Состав

- **Лабораторные № 1–8** — отдельные задания по основам программирования, вычислениям, работе с файлами и простым структурам данных.
- **`lab7/`** — заголовочный файл `Point4D` и связанные исходники.
- **`lab6/` и `lab8/`** — примеры текстовых входных и выходных файлов для соответствующих лабораторных.

## Сборка и запуск

В корне нет общей конфигурации CMake, Make или единого решения Visual Studio. Для выбранной лабораторной изучите исходники и скомпилируйте необходимые файлы `.cpp` подходящим C++-компилятором. Некоторым работам нужны текстовые входные файлы в рабочем каталоге процесса.

Единой команды сборки нет: расположение исходников и зависимости отличаются между заданиями.

## Примечания

- Входные и выходные текстовые файлы сохранены там, где являются частью лабораторной.
- Репозиторий не преобразован в одно приложение.
- Перед использованием результатов проверяйте выбранную лабораторную отдельно.
